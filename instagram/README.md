# Piezas para el feed de Instagram

Cuadradas, 1080×1080, en orden de carrusel. Capturas de las apps reales con
datos inventados.

| Archivo | Pieza |
|---|---|
| `feed/kinetic-1-ficha.png` | La ficha de cada paciente, completa |
| `feed/kinetic-2-facturacion.png` | Factura a ARCA sin salir de la app |
| `feed/kinetic-3-cierre.png` | Se adapta a cómo trabaja tu consultorio |
| `feed/vetadmin-1-ficha.png` | Toda la ficha de cada paciente, en una pantalla |
| `feed/vetadmin-2-turnos.png` | La agenda del día, sin planilla ni cuaderno |
| `feed/vetadmin-3-ventas.png` | Lo que entró y lo que falta cobrar, al día |
| `feed/vetadmin-4-movil.png` | La clínica entera, también en el teléfono |
| `feed/vetadmin-5-cierre.png` | Se adapta a cómo trabaja tu veterinaria |

Cada app tiene su color: Kinetic en teal, VetAdmin en ámbar. Las de VetAdmin
se regeneran desde `marketing/mockups/` del repo VetAdmin; las de Kinetic
están retocadas sobre la imagen (el generador original se perdió).
